# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

If you discover a security vulnerability, please report it by [opening an issue on the forge](https://forge.infrasouveraine.fr/dxsk/repos-manager/issues/new) with the `[SECURITY]` prefix in the title. The GitHub repository is a read-only mirror and is not monitored for reports.

Do not include exploit details in public issues. If the vulnerability is sensitive, contact the maintainer privately through their [forge profile](https://forge.infrasouveraine.fr/dxsk) first.

We will acknowledge the report within 48 hours and provide a fix as soon as possible.
